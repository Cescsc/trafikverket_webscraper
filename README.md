# Trafikverket Webscraper

A small Selenium scraper for checking driver test availability at Trafikverket.

This project was created in September 2023 as a personal tool to automatically check whether a time slot is available for a driving test.

## Requirements
- Python 3.8+
- Google Chrome
- ChromeDriver
- Selenium

## Install
```bash
git clone https://github.com/Cescsc/trafikverket_webscraper.git
cd trafikverket_webscraper
python -m venv venv
source venv/bin/activate
